# 教学解释与培训课件 Director Profile

## 场景目标
把复杂知识、政策或概念转成学习者能够理解、辨析和应用的认知路径。

## 推荐叙事
学习目标/问题 → 概念 → 原理 → 结构/过程 → 案例 → 对比/误区 → 应用 → 回顾。

## 优先识别的真实关系
定义-例子、原理-结果、过程、比较、层级、系统、误区-纠正。

## 视觉判断偏好
解释型视觉优先，复杂原理后给案例或类比；术语首次出现要解释。

## 优化重点
按学习者认知路径重组材料；政策解读突出概念、依据、适用边界与案例，表达生动与事实准确同步保持。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
