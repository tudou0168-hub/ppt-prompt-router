# 政府年度/半年总结 Director Profile

## 场景目标
把政府机关年度总结、半年总结和阶段性工作总结，从公文式材料重组为适合领导现场听取的逐页语义导演稿，让领导快速掌握“今年抓了什么、形成什么变化、下一步怎么干、哪些事项需要关注或支持”。

## 推荐叙事
先服从用户已经确认的章节顺序，再在章节内部建立领导判断链。常见主线为：年度/阶段总判断 → 重点工作与代表性成效 → 数据变化与机制经验 → 下一步重点任务 → 问题与建议/支持事项 → 收束提升。

## 年度总结专用提炼
- 成效页围绕：**抓了什么 → 怎么抓的 → 抓到什么程度 → 取得什么结果 → 体现什么变化**；
- 下一步围绕：**目标 → 重点任务 → 推进抓手 → 预期成效**；
- 问题建议围绕：**当前情况 → 实际影响 → 工作需求 → 建议支持事项**；
- 工作事实优先提炼为工作抓手，数据变化优先提炼为实际成效，具体做法优先提炼为机制经验，工作进展优先提炼为阶段判断；
- 页面正文保留领导最值得关注和记住的信息，完整口径、推进过程、典型案例与补充说明进入 Speaker Notes。

## 优先识别的真实关系
结论-证据、总分支撑、目标-进展、任务-成果、数据-变化、机制-成效、递进、时序、流程、闭环、汇聚、对比、问题-影响-需求。

## 视觉判断偏好
庄重、克制、清晰、有机关汇报质感。关键成果、阶段判断和需要领导关注的事项形成视觉锚点；页面空间结构跟随真实关系、信息主次和节奏意图自然变化。等权并列信息适合简洁分区或卡片，递进、流程、汇聚、对比、系统、证据关系优先召回对应结构族或采用自由构图。图片承担事实证据和场景证明，可根据页面角色采用侧证据、横幅、局部大图、背景图或小型佐证等不同角色。

## 优化重点
先形成整套故事，再组织章节；先明确页面任务，再安排页面内容。标题优先形成总结句、判断句和方向句；事实与数据保持原始依据，表达可按领导汇报需要完成归纳、合并、拆分、重组和凝练。全篇节奏综合页面角色、Audience Move、真实关系和信息密度形成锚点、密集、舒展与过渡之间的自然变化。

## 交接方式
形成 `presentation_plan.md`，逐页使用 Director Kernel 的六字段：`page_role / audience_move / relationship / hierarchy / rhythm_intent / visual_semantics`。页面任务映射 Audience move，核心观点映射 Core message，内容关系 + 信息主次 + 表达意图共同成为 Stage 2 的 Layout、Page Rhythm、Visualization 和视觉重心语义来源；具体 page-scale composition、Native Shape、SVG、图片融合和视觉实现交由 PPT Master 原生 Strategist / Executor 完成。
