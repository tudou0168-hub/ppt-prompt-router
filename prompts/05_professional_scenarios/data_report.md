# 数据报告与经营分析 Director Profile

## 场景目标
让管理层看清数据背后的变化、原因、风险与行动。

## 推荐叙事
核心发现 → 关键指标 → 趋势/结构 → 差异 → 原因 → 风险 → 管理含义 → 行动。

## 优先识别的真实关系
趋势、比较、结构、漏斗、差异、相关、预测（有依据时）、证据-结论。

## 视觉判断偏好
数据结论优先；图表是证据，不是装饰。

## 优化重点
每页围绕一个管理结论组织指标与图表，多个图表共享同一分析问题；所有基准来自材料或清晰标注的依据。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
