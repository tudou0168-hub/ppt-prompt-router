# 课程作业PPT Director Profile

## 场景目标
清楚展示作业问题、研究/实践过程、证据、结论和反思，回应评分标准。

## 推荐叙事
任务标准 → 问题 → 方法 → 过程 → 结果 → 分析 → 结论 → 反思。

## 优先识别的真实关系
问题-方法-结果、过程、证据-结论、比较。

## 视觉判断偏好
学术/课程规范、逻辑清楚，不追求过度商业化包装。

## 优化重点
同时呈现方法、过程、结果和反思，让视觉包装服务于证据和评分标准。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
