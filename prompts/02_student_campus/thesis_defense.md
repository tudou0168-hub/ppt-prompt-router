# 毕业论文答辩PPT Director Profile

## 场景目标
证明研究问题成立、方法可靠、结果有意义，并能回应质疑。

## 推荐叙事
研究背景 → 问题/假设 → 方法 → 数据/结果 → 讨论 → 贡献 → 局限 → 结论。

## 优先识别的真实关系
研究问题-方法-结果、变量关系、对比、因果（仅有证据时）、证据-结论。

## 视觉判断偏好
学术可信、图表清晰、方法与结果可追踪。

## 优化重点
围绕研究问题组织答辩，结论与证据保持对应，并主动呈现研究边界与局限。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
