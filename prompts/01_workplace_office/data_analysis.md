# 数据分析PPT Director Profile

## 场景目标
从数据回答具体管理问题，找出变化、原因、风险和动作。

## 推荐叙事
管理问题 → 核心发现 → 指标/趋势 → 结构拆解 → 差异/异常 → 原因 → 启示 → 行动。

## 优先识别的真实关系
趋势、比较、构成、漏斗、差异、相关、目标-实际、原因-结果。

## 视觉判断偏好
图表服务结论，少量关键数字形成锚点；证据和解释分层。

## 优化重点
围绕管理问题组织数据，优先突出少量关键指标和趋势；相关性与因果分层表达，因果判断以充分证据为依据。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
