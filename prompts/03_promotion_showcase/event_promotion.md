# 活动宣传PPT Director Profile

## 场景目标
让目标人群理解活动为什么值得参加、能获得什么、如何参与。

## 推荐叙事
吸引点 → 价值/主题 → 内容/嘉宾 → 体验/日程 → 参与方式 → 行动。

## 优先识别的真实关系
价值-内容、时间、参与路径、亮点层级。

## 视觉判断偏好
传播感强、信息扫描快，重点时间地点和行动明确。

## 优化重点
先建立参加理由和价值，再呈现内容、日程与参与路径；视觉重点始终服务时间、地点和行动信息。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
