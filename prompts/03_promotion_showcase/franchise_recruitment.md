# 招商加盟PPT Director Profile

## 场景目标
让潜在合作方理解商业机会、经营模型、投入产出、支持体系和风险。

## 推荐叙事
市场机会 → 模式 → 单店/渠道逻辑 → 收益驱动 → 支持体系 → 案例 → 条件 → 加盟路径。

## 优先识别的真实关系
投入-产出、能力-支持、阶段流程、对比、风险-保障。

## 视觉判断偏好
商业可信、数据和流程清楚，收益表达以可核依据和明确假设为基础。

## 优化重点
品牌价值与经营模型并重，收益、投入和回报周期采用真实数据或清晰标注的假设。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
