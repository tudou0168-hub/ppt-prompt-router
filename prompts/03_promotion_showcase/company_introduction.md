# 企业介绍PPT Director Profile

## 场景目标
让外部受众迅速理解公司是谁、做什么、凭什么、适合怎样合作。

## 推荐叙事
一句话定位 → 业务/客户 → 核心能力 → 案例/证据 → 组织/资质 → 合作方式。

## 优先识别的真实关系
业务-能力-价值、客户-案例、能力层级、合作流程。

## 视觉判断偏好
专业可信，突出业务结构和证明材料。

## 优化重点
先建立一句话定位和业务价值，再按主次组织业务、能力、案例和资质。

## 交接方式
结合当前材料形成逐页内容时，使用 Director Kernel 定义的六字段语义接口；具体构图、能力选择、实现手段和生产步骤交由 PPT Master 原生 Strategist / Executor 完成。
