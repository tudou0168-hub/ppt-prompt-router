# 03_服务质效

这一页重点说明大厅服务在业务增长中的运行质效。上半年累计办理各类业务四十三万四千零六十九件，日均三千五百二十九件，同比增长百分之十二点九。在线上协同方面，线上办件二十二万八千三百六十七件，占比百分之五十二点六，较去年同期提高零点七个百分点。企业主体业务二十七万六千九百二十四件，占总量百分之六十三点八，显示服务企业仍是大厅业务的重要支撑。作为补充口径，截至六月三十日，市场主体存量十一万八千四百五十六户，较去年净增六千八百二十二户；纳税人八万五千七百二十户，较去年增长一万零八百三十五户。总体看，业务增长、线上协同和企业服务在同一时期并行推进。

# 05_民生机制

这一页说明服务触点如何延伸到基层和群众身边。“一表通”已建立任务部署、督办整改、成效复盘的全链条闭环，并依托个人数仓推动基层数据一次采集、多方复用。上半年已对二十个区直部门、六个办事处和一百零一个村社区完成全覆盖摸排，配置四百一十一个系统账号，并将区级报表精简至一百一十二项。与此同时，联合区总工会打造的政务加工会服务平台已服务群众两万余人次；有诉即办机制上半年解决群众各类诉求一百九十七件。政务加健康和政务加婚检属于已开展的服务场景。这里需要强调，一表通的闭环机制与这些场景并非一条虚构流程，而是共同支撑基层减负和群众体验的并列能力。

# 06_下半年谋划

下半年工作的落点，是把阶段改革转化为常态服务能力，让高效便捷的政务服务触手可及、时刻在线。围绕这一目标，第一是攻坚任务与民生实事，牵头任务编制网络计划书、挂图作战，配合任务实行台账管理。第二是招商包保，推动项目落地，并对企业诉求实行收集、办理、反馈、销号的全链条管理。第三是深化审批改革，承接新事项、巩固已上线事项，聚焦多次跑和往返跑堵点。第四是提升专区增值服务，通过资源联动和服务下沉打通惠企服务末梢。第五是数字赋能，继续完善高小·i政务智能体研发建设，推进免证办和一表通；其中高小·i仍属继续研发建设，不表述为既成能力。第六是服务下沉，持续完善十五分钟便民服务圈，延伸惠企服务，健全有诉即办和微创新机制。六项任务并列推进，共同服务于政务服务持续提质增效。
