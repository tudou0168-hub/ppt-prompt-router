审批服务局

2026年上半年工作总结及下半年工作谋划

管委会：

2026年以来，审批服务局坚决贯彻党工委、管委会决策部署，确立__“12345”__工作思路，强化__“高效办成一件事”__改革牵引，突出“利企、便民”__两大方向__，持续推进“营商环境提升优化、行政审批提速增效、政务服务提档升级”__三个专项行动__，全面提升政务服务标准化、便利化、智慧化、增值化__“四化”水平__，突出抓好__五项重点工作任务__。现将工作汇报如下：

<a id="_Toc1180453999"></a>一、重点工作完成情况

<a id="_Toc1436430207"></a>__（一）扛牢二十项攻坚任务，锚定目标稳中有进__

__牵头任务完成情况（2项）：第124项__任务深化“高效办成一件事”改革，重点事项平均办理时限压减至71.24%（目标80%）；企业服务专区已打造完成并平稳运行。__第127项__任务优化“15分钟便民服务圈”建设，指导沟赵办事处完成标准化提升试点；全区“一网通办”占比达91.18%（目标90%），“免证办”高频事项达到300余项；做优“书记亲商助企服务热线”，自热线开通以来累计受理诉求103件，回访销号103件，办结率达100%（目标98%），确保企业诉求高效化解。两项任务均完成进度80%。

__配合任务完成情况（11项）：__党的建设4项、高质量发展2项、高效能治理2项、全员招商引资1项、开放建设高地1项、营商环境优化1项，上述工作根据牵头部门安排，均在稳步推进。

<a id="_Toc71329475"></a>__（二）招商包保双向发力，营商环境提升优化__

招商引资方面，多次与童竞天域数字文娱竞技中心项目方对接洽谈，6月6日已通过区招商引资工作周例会研判并实质落地，目前正在走签约流程，签约额1.5亿元，完成全年目标任务150%。对党工委、管委会领导外出招商任务统筹协调，相关行程安排有序推进。

企业包保方面，主要负责人带头走访海泰机械、赛伦交通等47家企业，面对面座谈交流，了解生产经营状况与发展诉求。按月汇总走访情况，建立问题台账，实行“收集—交办—督办—反馈”闭环管理。上半年累计收集问题诉求26件，均已办结，解决率100%。

<a id="_Toc538611299"></a>__（三）对标杭州先进经验，行政审批提速增效__

__一是深化“高效办成一件事”改革。__联合市场监管局推出个体工商户智能审批全生命周期特色“一件事”，依托智能审批设备打造“集成式”服务，压减环节20%，压减材料50%，跑动次数压减至1次，办理时限压缩至1个工作日，累计办件4.6万件。推动工程建设项目审批从“一件事”向“一类事”转变，社会投资类项目审批时限由39天压减至25天（压减35.9%），政府投资类由41天压减至30天（压减26.8%）。__二是建设企业综合服务专区。__按照“一窗受理、立体辅导、全程帮办、集成服务”理念，搭建“1\+3\+N”全域政务服务矩阵，配套建立三级协同联动、集成联审联批、零距离暖心服务、全要素赋能增值四项机制。推动各涉企审批职能部门集中驻点、集成办公、并联审批，有效解决企业多头跑腿难题。同时，整合政策、科创、金融、人才、法律、兜底保障六大服务板块，覆盖企业全生命周期发展需求。专区运行以来累计服务1000余人次，服务项目审批138件，提供增值服务496件。__三是探索建设政务服务智能体。__聚焦群众办事痛点，筹建“高小·i”政务智能体，打造“边聊边办、智能预检、自动申报”模式，实现全流程“一口清、一次办”。同时为窗口人员配备“窗口助手”，智能审核材料，提升审批效能。力争实现省市领先、中部一流、全国典型的目标。

<a id="_Toc796530188"></a>__（四）聚焦聚力民生实事，政务服务提档升级__

__一是牵头“一表通”工作。__成立“一表通”工作专班，构建“任务部署—督办整改—成效复盘”全链条闭环管理体系，依托“个人数仓”推动基层数据“一次采集、多方复用”。对全区20个区直部门、6个办事处、101个村（社区）全覆盖摸排，筛选两个办事处先行试点。配置系统账号411个，对照省市报表规范清单，精简区级报表至112项，从源头减少多头填报、重复报送。__二是办好民生实事。__2026年度市级重点民生实事涉及我局牵头1项，即“新增公积金缴存20万人”，高新区任务为新增1.6万人。截至目前，已新增开户单位1459家、新增缴存职工8560人，完成率53.5%。__三是提升办事体验。__联合区总工会打造“政务\+工会”服务平台，集政务服务、法律维权、零工就业、休憩阅读于一体，已服务群众2万余人次。联合郑州西区中医院打造“政务\+健康”服务场景，打通便民服务“最后一米”。联合公共事业部打造“政务\+婚检”服务模式，将免费婚检前置嵌入婚姻登记环节，实现“领证即检、一站服务”，为准新人提供便捷高效的健康保障。同时，积极回应群众诉求，在政务大厅配置充电宝、咖啡机、饮料机等便民设施，增强办事群众的体验感、获得感。

<a id="_Toc2017297965"></a>__（五）党建引领保障护航，压实安全稳定责任__

__一是深学细悟，树牢正确政绩观。__召开党员大会部署正确政绩观学习教育，党支部书记带头讲党课，开展读书班2次、专题研讨4次、警示教育2次。创新党支部联建共建，紧扣项目、企业、安居、人才、民生五大板块推动党建与业务融合。紧盯政务服务重点环节，通过日常监督、明察暗访等方式整治群众身边不正之风，累计下发工作提示函13次，健全常态化监督机制。__二是分级负责，守牢安全生产底线。__构建“统一领导、分级负责”安全工作架构，全员分包负责大厅各区域消防安全，物业具体执行设施维护。严格落实“1020”工作机制和“二分之一工作法”，采取“日巡查、周检查、月督查”方式，定期组织安全培训与问题通报，坚持预防为主、快速响应，力争早发现、早处置，杜绝安全隐患，确保大厅运行平稳有序。上半年累计开展消防检查22次，设施设备检查维保24次，物业综合培训、消防演练28次。__三是源头化解，抓实信访稳定工作。__建立健全双人值班和领导带班巡查机制，确保大厅全天有人值守、突发情况快速处置。依托学雷锋志愿服务站、党员先锋岗和有诉即办（“办不成事”反映）窗口，完善有诉即办闭环，实行“接诉—处置—反馈—回访”全流程管理，不积压推诿群众诉求，灵活开展延时服务。坚持问题大厅化解、矛盾现场处置、分歧就地解决，提前消除苗头隐患，减少群众投诉，上半年共解决群众各类诉求197件，有效杜绝纠纷升级为信访案件。

<a id="_Toc255078919"></a>__（六）大厅运转高效有序，业务办理质效双升__

上半年，审批服务局高效统筹业务办理与服务提升，大厅累计办理各类业务434069件，日均办件量达3529件，同比增长12.9%。其中__线上办件量__228367件，占比52.6%，同比提高0.7个百分点。__企业办事持续增长__，企业主体业务办理量达276924件，占总量63.8%；__市场主体__存量截止6月30日达118456户，较去年净增长6822户，涨幅达6.11%；__纳税人__85720户，较去年增长10835户，增长率14.47%。服务效能持续提档升级，市场主体活跃度、企业和群众办事便利度、满意度稳步提升。在2026年度全市行政审批和政务信息管理系统工作会议上，高新区审批服务局率先作典型发言。

<a id="_Toc734032221"></a>二、存在问题及建议

__一是__干部队伍建设需进一步加强，亟需提升专业能力，锤炼工作作风，建议配齐政务服务大厅缺岗人员，加强培训，提升政务服务规范化水平。__二是__大厅信息化运维支撑能力保障不足，目前处于维保脱保状态，存在系统安全风险，运行不畅，建议管委财政给予支持，保障系统稳定运行。

<a id="_Toc1733469979"></a>三、下半年工作谋划

<a id="_Toc1666781851"></a>__（一）攻坚任务扛稳抓牢，民生实事落地见效__

__一是__将党工委确定的二十项重点攻坚任务摆在首要位置，__牵头任务__编制网络计划书，挂图作战，明确时间节点，责任具体到人，__配合任务__实行台账管理，主动对接，按照既定时序，合力攻坚推进，确保全年任务按时保质完成。__二是__抓实日常安全巡查、隐患排查整改、安全警示教育等工作，落实常态化排查、闭环式整改机制，筑牢安全底线，提升安全管理规范化水平。__三是__扎实推进民生实事工作，紧盯年度目标任务，以更大力度、更实举措，确保高质量完成全年目标。

<a id="_Toc1825878289"></a>__（二）招商引资持续发力，包保服务常抓不懈__

__一是__推动现有项目高效落地，持续跟进童竞天域数字文娱竞技中心项目，密切跟进河南紫源工程技术有限公司总部基地、中医药产品生产加工等项目，推动其尽早签约落地。__二是__深挖招商线索，利用企业服务专区等优势，持续挖掘招商线索，推进项目洽谈落地，力争全年超额完成招商引资任务目标。__三是__压实包保责任，做好47家包保企业服务，明确走访频次和工作要求，力争企业走访率、问题解决率等指标排名全区前列。对企业诉求实行“收集—办理—反馈—销号”全链条管理，限时解决、及时上报、跟踪落实，工作成效体现在问题解决和企业满意度提升。

<a id="_Toc2142571240"></a>__（三）对标先进深化改革，审批效能再上台阶__

持续对标杭州先进经验，__一是__做好2026年新上线事项承接，聚焦企业经营、群众安居就业需求，高质量落实国家新一批重点事项清单。__二是__巩固提升已上线事项成效，聚焦“多次跑、往返跑”堵点，深度分析已上线事项运行情况，通过办件回访、“我陪群众走流程”等措施健全问题发现整改机制，力争已上线重点事项办理时限压缩至80%以上。__三是__打造高新区特色“一件事”。依托企业服务专员，靠前辅导帮办，对重点项目开辟“绿色通道”，提供从立项到竣工的全周期跟踪服务，做到“企有所呼，我有所应；企有所求、我有所为”，持续优化辖区政务营商环境。

<a id="_Toc1189037784"></a>__（四）专区功能持续优化，增值服务提质扩面	__

__一是__持续深化与人才招聘、产业投资、金融平台等各类优质资源主体的双向对接联动，丰富增值服务内容，扩大宣传推介。二__是__加强与经济发展部、投资促进部、投控集团等部门联动，健全与办事处、园区运营中心对接机制，将政策宣讲、业务代办、咨询答疑、诉求收集处置等各类惠企服务全面下沉，打通企业服务“最后一公里”。三__是__梳理企业服务专区创新举措、协同机制及典型案例，将成熟可行的服务模式、高效务实的工作机制固化为常态化制度规范，着力打造辨识度高、实效性强的高新区企业服务特色品牌。

<a id="_Toc1822700353"></a>__（五）数字赋能纵深推进，智慧应用多点突破__

__一是__瞄准国内前沿，探索“人工智能\+政务服务”。继续完善“高小·i”政务智能体研发建设，赋能区级“特色一件事”落地，让群众办事更加智能高效。__二是__推动“免证办”改革迭代升级，持续对接市级证照免提交清单，做好动态调整与落地承接，完善数据共享调用机制，扩大电子证照、电子印章、电子材料应用场景，力争年底前“免证办”事项覆盖面进一步扩大。__三是__深化“一表通”改革落地实效，对照郑州市工作要求，完成清单样表及配套《数据项说明》的系统化、标准化录入，健全基层报表

清单常态化、动态化、精细化管理制度，保质保量完成全年既定

任务，持续巩固基层减负成效。

<a id="_Toc270608416"></a>__（六）服务触角下沉延伸，助企便民精益创新__

__一是__持续完善“15分钟便民服务圈”建设。推广沟赵试点经验，规范各中心场地、窗口及设备配置，指导双桥、科学城便民服务中心新大厅规范建设。对照省市发布的事项清单，联合各业务条线职能部门梳理事项，培训业务人员，持续提升基层便民服务效能。__二是__延伸惠企服务链条。针对不同规模类型企业主动上门服务，做好政策精准推送、个性化流程辅导、跨部门协调帮办等工作，实现从“被动审批”向“主动服务”转变。__三是__健全“有诉即办”跟踪问效机制，拓宽“书记亲商助企服务热线”渠道，联合经济发展部增设园区智能体“书记热线”模块，持续叫响“高小新”服务品牌。__四是__打造政务服务“微创新”典型案例。立足自身服务场景，主动探索流程优化、数字赋能、服务升级等务实创新举措，力争探索推出可落地、可复制、惠及群众企业的典型案例，进一步增强办事群众获得感、幸福感、满意度。

下半年，审批服务局牢固树立和践行正确政绩观，坚决贯彻党工委、管委会决策部署，内强素质转作风，外树形象优服务，让高效便捷的政务服务触手可及、时刻在线，以一流营商环境厚植高新区发展沃土，为高新区高质量发展贡献政务力量。
