# PPT Semantic Vocabulary

这是专业导演的有限语义词汇。导演表达业务语义，PPT Master Strategist再把它翻译为当前版本自己的设计空间。

## page_role
executive_summary / context / problem / finding / achievement / evidence / comparison / mechanism / architecture / roadmap / risk / decision / teaching / example / section / closing

## relationship
parallel（并列） / progression（递进） / causal（因果） / support（总分支撑） / convergence（汇聚） / divergence（发散） / process（流程） / cycle（闭环） / time（时间） / comparison（对比） / hierarchy（层级） / matrix（矩阵） / system（系统） / evidence（主张-证据） / none（普通并列或无需特殊关系）

关系可以组合，如 `progression + convergence`；选择材料中最真实、最能帮助受众理解的关系。

## hierarchy
用自然语言明确主角、支撑、证据、背景，例如：`主角=最终成效；支撑=三类改革动作；证据=关键数据与案例`。

## rhythm_intent
使用自然语言描述页面在全篇中的节奏任务，例如：
- 形成阶段停顿并强化单一结果；
- 承载多组数据和证据；
- 章节转折，需要舒展与留白；
- 常规信息承载，保持稳定推进。

Strategist再结合当前 PPT Master的 page rhythm定义完成映射。

## visual_semantics
描述画面需要传达的业务意义，例如：`多项改革共同托举一个结果`、`两个方案在同一标准下被比较`、`能力逐层构成完整系统`。具体几何和图形形式由 PPT Master自主选择。
