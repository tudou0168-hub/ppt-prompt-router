# Router 3.1.3 → PPT Master 4.4+ Mapping Protocol

## 三层职责

**Router handoff**：选择并内联专业上下文；它不直接生成页面计划。

**Director**：当前主智能体接收 Router handoff 后，确定讲什么、为什么讲、真实内容关系、主次和节奏意图，形成 `presentation_plan.md`。

**Strategist**：从 `presentation_plan.md` 开始，结合 Stage 1 确认结果、材料、模板和当前项目，把导演语义二次编译为 PPT Master 当前版本自己的 Design Spec / Spec Lock、Page Rhythm、Layout、Visualization、资源与全篇视觉系统。

**Executor**：依据 Master 原生权威完成实际几何、SVG、Native Shape、图片、图表、Visual Job Router、跨页视觉语言、动画/转场等视觉实现。

## 六字段二次编译

| Director字段 | Strategist理解 | PPT Master原生产物落点 |
|---|---|---|
| `page_role` | 本页承担的沟通任务 | §IX页面角色、目的与内容组织 |
| `audience_move` | 观众看完前后的认知/决策变化 | §IX `Audience move` 与 Core message |
| `relationship` | 并列、递进、因果、流程、证据等真实关系 | §IX `Layout` / `Content` 与 Visualization Recall 语义 |
| `hierarchy` | 主角、支撑、证据、背景 | §IX `Core message` / `Content` / `Layout` 主次结构 |
| `rhythm_intent` | 页面在整套中的停顿、承载、舒展或过渡任务 | 当前 Master 的 page rhythm |
| `visual_semantics` | 页面希望传达的业务意义 | §IX `Layout` / `Visualization` / `Native shape suggestion` 的语义依据 |

## Stage 2 设计激活

1. **Visual Style 统一视觉气质**：颜色、字体、线条、材质、图像处理、图标和品牌/政务气质形成项目级统一；页面空间结构由每页 `relationship / hierarchy / rhythm_intent / visual_semantics` 单独决定。
2. **关系驱动构图**：`relationship` 存在明确结构语义时，Strategist 先做一次语义 Visualization Recall / 能力族召回，再结合材料、模板和页面角色选择候选、组合候选或自由设计。
3. **卡片是局部手段**：等权并列、KPI、短清单或需要容器承载的信息适合卡片/面板；递进、流程、汇聚、对比、层级、系统、主张-证据等页面优先体现对应真实结构。
4. **全篇节奏综合判断**：Page Rhythm 综合页面角色、Audience Move、关系、信息密度和章节位置形成 anchor / dense / breathing 等当前版本语义，关键成果与章节转折主动形成视觉停顿。卡片依赖、连续 dense 与构图重复用于审阅诊断，不形成机械配额。
5. **图片角色随页变化**：图片可承担事实证据、场景证明、视觉锚点、背景氛围或局部佐证；位置和尺度跟随页面语义与构图，形成侧证据、横幅、局部大图、背景图、小型佐证等多样角色。
6. **Executor 解决真实页面问题**：先完成语义骨架和 page-scale composition，再由 Visual Job Router、SVG Effects、Native Shape、Charts / Diagrams 等能力解决焦点、边界、方向、融合、层次和可读性。

Strategist 基于用户最终确认、材料事实、整套故事线和当前 Master 定义重新编译，而非机械复制字段。计划、Design Spec、Spec Lock 和页面产物是正常研发审计证据；不因此引入状态机、字段级回执或独立质量门禁。

## 权威顺序

用户明确约束与事实材料 → PPT Master 用户确认后的原生合同 → `presentation_plan.md` → Profile 经验。

## 能力地图读取时机

Director 阶段专注材料和六字段语义。Stage 2 从 `presentation_plan.md` 开始，并按当前页面需要读取 `ppt_master_design_capability_map.md`。能力地图用于扩大候选设计空间，最终选择继续由当前 Master 完成。
