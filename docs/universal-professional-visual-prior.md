# Universal Professional Presentation Visual Prior

这是所有专业演示共用的高级视觉判断方法。它不决定品牌、行业风格、坐标、固定图形、卡片数量或页码级版式；Router Profile 继续负责专业内容，PPT Master 继续负责具体设计与实现。

## 1. 页面任务

先判断本页要让观众理解、记住、比较、相信、判断、选择、决策、行动、学会，还是建立整体认识。页面视觉不是内容的容器，而是完成这项沟通动作的方式。

## 2. 核心观点

每页先找出观众只能记住一句时应留下的判断。它成为第一视觉焦点；标题、证据、支撑与注释必须有明确重量差，不能默认等权。

## 3. 真实内容关系

从材料识别并列、主次、层级、因果、时序、流程、对比、输入输出、系统协同、组成、依赖、问题—原因—措施、目标—任务—结果、观点—证据、决策—依据或其他真实关系。关系存在时，让主空间组织帮助观众直接感知它；没有特殊关系时，清晰稳健的排版就是正确答案。

## 4. 信息层级

以“核心观点 → 主证据或主关系 → 次级支撑 → 口径、来源与注释”建立阅读顺序。通过尺度、位置、字号、字重、对比、留白、色彩和图形重量表达层级，而不是把不同重要性的内容都装入同样的框。

## 5. 证据角色

数据、照片、截图、流程、案例和引用必须说明它们在证明、解释、比较、定位或建立情境中的作用。数据不孤立：当材料支持时，呈现比较基准、时间、范围、口径或含义；材料不支持时，明确缺口而不编造。

## 6. 整页空间动作

先决定整张页面的主空间动作，再安放局部元素：可以是一个结论统领证据、一条关系贯穿全页、一处大证据与少量解读、一个对照面、一个系统承托层，或一段有意留白的停顿。避免从多个安全卡片开始拼凑页面。

## 7. 形式选择

图表、表格、关系结构、裸文本、图片、大数字、卡片或图标都是表达语言，不是预设答案。表格和模块适合事实核验、精确值、明细对照或真实并列；结构、图表和图像只在它们比简单排版更准确传达关系时使用。

## 8. 跨页节奏

让故事自然形成 Anchor、Dense、Normal、Breathing、Data、Structure、Decision、Closing 等不同阅读体验。统一视觉语言不等于同一构图；不要用机械数量规则制造变化。

## 9. 真实 PNG 审阅

SVG 检查通过后，仍需看最终 PNG。先消除文字越界、重叠、页码/标题碰撞、不可读和元素冲突；再判断第一眼焦点、核心观点、关系、层级、构图、场景适配与跨页节奏。视觉审阅只能修复允许的原子执行问题，不能掩盖错误的页面策略。
